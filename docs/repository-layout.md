# Repository layout

This inventory describes the tracked root layout of `get-h3/sdk-python`. It
complements, rather than replaces, the package-focused structure in
`AGENTS.md` and `CONTRIBUTING.md`. The implementation and protocol repositories
remain authoritative for behavior and wire schemas; this document is the
repository-level map.

## Tracked generated registries and fixtures

These files are intentionally tracked repository content, not disposable local
state. Do not remove them or broaden ignore rules to hide them:

- `.coding-hermes/board/events.jsonl`
- `.coding-hermes/board/tasks.jsonl`
- `.coding-hermes/board/fixtures.jsonl`
- `.coding-hermes/board/schema.sql`
- `.vfs/graph/edges.jsonl`
- `tests/schemas/v1/*.json`

`src/h3_harness/protocol.py` is also generated: `make generate` derives it from
the selected H3 protocol schema directory, preferring an explicit
`--schema-dir`, `H3_SCHEMA_DIR`, a sibling `../protocol` checkout, and finally
the tracked `tests/schemas/v1/` fixtures.

## Intentional local-only artifacts

The following are ignored by design because they are machine-local logs,
working state, caches, build products, or temporary test output. They are not
part of the SDK source layout and must not be substituted for the tracked
registries and fixtures above:

- GitReins runtime state: `.gitreins/logs/`, `.gitreins/history/`,
  `.gitreins/usage.jsonl`, and `.gitreins/tasks.yaml`.
- Hilo local state: `.vfs/graph/.last_reconcile`,
  `.vfs/graph/.last_warm`, `.vfs/graph/graph.db`, and
  `.vfs/graph/graph.db.wal`.
- Local engine/database artifacts: `dagger.db*` and `/board.db`.
- Local board database/parquet state:
  `.coding-hermes/board/board.db`,
  `.coding-hermes/board/board.db.wal`,
  `.coding-hermes/board/*.parquet`,
  `.coding-hermes/board/*.duckdb`, and
  `.coding-hermes/board/board.jsonl`.
- Build and environment outputs: `dist/`, `build/`, `.venv/`, and
  `*.egg-info/`.
- Python and test caches: `__pycache__/`, `*.pyc`, `.pytest_cache/`,
  `.ruff_cache/`, `.coverage`, and `.benchmarks/`.
- Temporary root audit scripts matching `/_*.py`.
- Local namespace and end-to-end output: `namespaces/` and `e2e-output/`.

An ignored path is an intentional local-only exception, not evidence that a
similarly named tracked file or directory is expendable. Keep generated
registries and fixtures tracked, and keep local-only artifacts out of commits.
