# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities to the maintainers via GitHub Security Advisories on the [get-h3/sdk-python](https://github.com/get-h3/sdk-python) repository.

We aim to respond within 48 hours and provide a fix within 7 days of confirmation.
