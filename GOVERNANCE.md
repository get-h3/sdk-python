# Governance

This document describes the governance model for the H3 Python SDK project.

## Roles

- **Maintainers**: Responsible for reviewing and merging contributions, managing releases, and enforcing the code of conduct.
- **Contributors**: Anyone who submits patches, documentation, or bug reports.

## Decision Making

Decisions are made through consensus among maintainers. For significant changes (new features, API changes, breaking changes), a design discussion should precede implementation.

## Pull Request Process

1. Open an issue describing the change before submitting a PR (for non-trivial changes).
2. All PRs must pass CI (tests + lint).
3. At least one maintainer must approve before merge.
4. The PR author is responsible for merging after approval.

## Release Process

Releases follow [Semantic Versioning](https://semver.org/). Maintainers publish releases to PyPI.
